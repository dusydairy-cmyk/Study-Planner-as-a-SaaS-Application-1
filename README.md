# StudyFlow — Smart Study Planner SaaS

**College project title:** *StudyFlow: A Cloud-Based Smart Study Planner and Academic Progress Management System*

A responsive student planner starter built with HTML, CSS, and JavaScript.

## Features
- Dashboard with task counts and completion rate
- Add tasks with subject, priority, and due date
- Mark tasks complete and filter by status
- Study schedule and subject-wise progress cards
- Weekly completion chart
- Responsive desktop and mobile layout
- Saves tasks in browser local storage

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Use **My Tasks → Add task** to create a task.

No packages or build tools required.

## Files
- `index.html` — application structure
- `style.css` — styling and responsive layout
- `app.js` — planner logic
- `README.md` — instructions

## SaaS extension plan
This is a front-end demo, not a production SaaS. It does not yet include login, shared cloud storage, admin management, or payments. To extend it:
1. Add Supabase authentication.
2. Create PostgreSQL tables for profiles, subjects, and tasks.
3. Apply row-level security so each student can access only their own records.
4. Replace local storage with database operations.
5. Deploy to Vercel or another static host.
6. Add free/premium plans and payment processing if needed.
